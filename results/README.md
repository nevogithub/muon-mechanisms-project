# Result tables

- `three_seed/` contains the claim-defining ResNet and TinyViT seed-level values, summaries, and paired contrasts.
- `mechanism_grid/` contains the aggregated MARS, momentum, Mu²-inspired, interaction, diagnostic, and time-to-threshold tables used by the final graph builder.
- `resnet_mars/` contains the cleaned fixed-auxiliary MARS sweep.

These are compact derived tables, not raw checkpoints or cluster logs. Standard deviations in the project material are sample SD unless a paired-difference statistic is explicitly labeled.
